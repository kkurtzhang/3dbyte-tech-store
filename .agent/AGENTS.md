# Portable ECC Library

The repository-root `AGENTS.md` is authoritative. The `.agent/` tree is a
portable ECC export for compatible harnesses; it is not one combined prompt.

Load only the component that matches the task:

- DAILY: common, TypeScript, and web rules; focused planning, test, review,
  security, and verification roles when their trigger applies.
- LIBRARY: off-stack language packs, specialist workflows, and content,
  investor, social, media, or research capabilities.

Do not scan or inject all rules, skills, roles, and workflows into a session.
If a harness cannot load these components lazily, configure a selective
TypeScript/web install rather than the full bundle.
