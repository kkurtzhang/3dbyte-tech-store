# October 2026 non-braces dependency remediation

This local change starts from integrated baseline
`3f55081b4e3ef9a9ac538fd369411c57719b32c6`, on branch
`fix/non-braces-remediation-20261013`. Medusa remains 2.15.5 and Strapi remains
5.48.1. All existing patches, advisory ignores and CI security thresholds are
preserved. Braces remains unresolved and was not tested or re-reviewed here.

## Evidence and limits

The saved October 8 audit JSON at
`artifacts/release-review-followup-20261008/security-release-audit-final-20261008.json`
identifies the lower advisories hidden by the CI threshold output. Its metadata
reports 8 low, 47 moderate and 1 high findings; historical CI reports 3 ignored
low findings. These counts are historical, not the result of this change.
The saved JSON contains 47 package/advisory entries, including one braces entry;
counts of entries, distinct advisory IDs and vulnerability totals differ.

Each non-braces advisory's affected and fixed ranges was checked against the
public GitHub Advisory API on October 13, and candidate releases/engines/peers
against the official npm registry. The table compares actual baseline and
remediation lockfile versions against those ranges, including remaining copies.
It covers 46 saved non-braces package/advisory entries across 38 advisory IDs.
34 entries are outside the checked ranges, 2 are partially remediated and 10
remain. Across these saved entries, 26 advisory IDs have no affected locked
version remaining. This is **offline range evidence, not a new audit count or an
exploitability assessment**. Newly disclosed advisories and complete current
audit coverage remain unverified; do not infer that 34 audit findings disappeared.

Public metadata and full logs are retained under
`/Volumes/MINI-M1/Codex/3dbyte-tech-store/artifacts/non-braces-remediation-20261013`.
`advisory-matrix.json` contains the exact historical paths and machine-readable
version/range comparisons. `registry/` and `advisories/` retain public metadata.

## Package decisions

Direct dependencies move to `qs` 6.16.0, Nodemailer 10.0.9 and React Router DOM
6.30.6. Existing transitive remediation selectors advance to published fixes for
PostCSS, Hono, DOMPurify, Morgan, Multer, IP address classification, Markdown,
fast-uri and brace-expansion. Brace-expansion is a separate package from braces.
The selector-parser 6.x and 7.x fixes stay on their original major versions.

Most consumers accept these updates in their upstream ranges: Medusa uses
Morgan `^1.9.1`, Multer `^2.0.2` and qs `^6.12.1`; Hono's MCP consumer uses
`^4.11.4`; express-rate-limit uses ip-address `^10.2.0`; AJV uses fast-uri
`^3.0.1`; PostCSS consumers use compatible 8.x ranges. Existing overrides remain
necessary for exact/older upstream pins: Strapi qs 6.15.2, DOMPurify 3.4.5 and
Markdown 14.1.1, Medusa Dashboard React Router DOM 6.30.3, and Strapi Nodemailer
8.0.5 (already overridden to 10.0.6 before this task). This change does not
introduce a new forced major-version substitution for those dependencies.

OpenTelemetry auto-instrumentations advances from 0.77.0 to 0.79.0, the smallest
checked parent release selecting all eight fixed DB instrumentations in its
own supported ranges. 0.78.0 still selects affected versions. The public Node
requirement (`^18.19.0 || >=20.6.0`) and API/core peers remain unchanged.
Its transitive SDK/instrumentation packages advance coherently to 0.221.0 and
2.10.0 alongside existing root SDK copies. The dependency update exposed
TS2742 for an inferred exported type; `createNodeAutoInstrumentations` now
explicitly returns its already imported public `Instrumentation[]` interface.
Declaration builds and consumers pass. New coverage verifies retained database
instrumentations, disabled filesystem instrumentation and health-route filtering.

No deprecated target release was chosen. Existing peer warnings and deprecated
dependencies remain in the baseline graph (including Medusa Express/picomatch
and Strapi CodeMirror/Zod warnings); this is not a general ecosystem cleanup.

## Remaining advisories and blocked compatible fixes

- React Router 6.30.6 fixes the DOM advisory but remains affected by the two
  advisories requiring React Router 7.18.0+. Medusa 2.15.5 and Strapi 5.48.1 do
  not support a blanket router-v7 substitution. Strapi's current stable 5.57.0
  still peers on `react-router-dom ^6.30.3`.
- `sanitize-html` 2.17.5 remains affected by both saved advisories. Fixes 2.17.6
  and 2.17.7 officially require Node `>=22.12.0`, while repository CI uses
  Node 20. The storefront Docker runtime already uses Node 22, but upgrading
  this package would leave CI outside its supported range. Coordinate a runtime
  baseline decision before adopting 2.17.7; no CI/security gate was changed here.
  The application's sanitizer excludes SVG animation, but that is not an audit
  waiver or a claim that the package advisory is cleared.
- `stream-json` 1.9.1 remains affected by three saved advisories requiring 3.6.0.
  Both Strapi 5.48.1 and current 5.57.0 pin 1.9.1 in data-transfer. Replacing it
  with 3.x would be an unsupported multi-major API/module migration.
- `csv-parse` 5.6.0 remains affected; the fix is 7.0.2. Medusa 2.15.5 declares
  `^5.6.0`. The first checked stable Medusa parent using `^7.0.2` is 2.21.0.
- selector-parser 7.1.6 fixes the 7.x copies and 6.1.3 fixes the older recursion
  advisory on the 6.1.x copy. The newer complexity advisory still covers 6.0.10
  and 6.1.3. Tailwind 3 and postcss-nested 6 require 6.x; even current typography
  0.5.20 pins 6.0.10. No major parser override was introduced.
- OpenTelemetry's eight DB instrumentations are fixed on the shared package
  path, but Medusa still brings PostgreSQL instrumentation 0.52.0 via
  `@medusajs/deps ^0.52.0`. Current Medusa 2.21.2 retains that range, so its
  `db.user` advisory remains on this separate path.
- `i18next-http-backend` 3.0.5 remains affected; the fix is 4.0.2. Medusa
  Dashboard 2.15.5 pins 2.4.2, already overridden to 3.0.5 before this task.
  No additional major override was applied. Dashboard 2.21.2 no longer declares
  this dependency, which is a potential benefit of a separately tested upgrade.
- `sprintf-js` 1.0.3 has no published fix for the saved precision advisory.
  It comes through Medusa CLI/deps, MikroORM migrations, Umzug, Rushstack and
  argparse. Do not invent a fixed version or waive the advisory.
- Braces is still unresolved, unchanged and outside this task's verification.
